# PICASSO TEAM | پیکاسو تیم

وب‌سایت رزومه و پورتفولیوی خلاق مهدی علیمحمدی، بنیان‌گذار و مدیر خلاق پیکاسو تیم.

## نسخه فعلی

- `index.html`: سایت تک‌فایلی واکنش‌گرا و آفلاین با فونت‌های محلی و لوگوی اصلی، هشت گروه خدمات و هشت جایگاه *نمایشی* برای نمونه‌کارها.
- `.nojekyll`: میزبانی آسان روی GitHub Pages.
- `README.md`: این فایل.

**توجه:** کارت‌های گالری فعلاً *تصاویر نمایشی طراحی* هستند و به‌عنوان کار واقعی کارفرما یا پروژه تکمیل‌شده معرفی نشده‌اند. بعد از دریافت نمونه‌کارهای اصلی، آنها را با گالری واقعی جایگزین می‌کنیم.

## نمونه‌کارهای آینده

- دسته‌بندی‌ها: عکاسی صنعتی، فیلم‌برداری، تدوین، گرافیک، برندینگ، تصویر/ویدیو هوش مصنوعی و طراحی سایت.
- تصاویر WebP بهینه‌شده در `assets/works/`؛ هر پروژه می‌تواند گالری تصاویر داشته باشد.
- برای ویدیوهای سنگین میزبانی خارجی و پخش درون‌سایت پیشنهاد می‌شود.
